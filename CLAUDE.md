# CLAUDE.md - the design language's home

Read `اقرأني.md` first (Arabic: what this home is and its laws), then `README.md` (the map), then parts أ and ب of
`DESIGN_LANGUAGE_BUILD_GUIDE.md` before styling anything in any of Jo's projects.

- **This folder is the master of Jo's design language** (since 2026-10-08). The copies inside Qimma, StandardsHub and the
  CBAHI PHC tool are mirrors written by `tools/ship.sh`; never edit a mirror. A change lands here, then ships.
- **The guide is Arabic and keeps its own voice and structure** (parts أ to ح, the appendix). New directions from Jo go in
  with their date and his words, verbatim.
- **A project's code and its own laws rule its surfaces** (StandardsHub's design skill and tests, PHC's shipped surfaces
  under part ز); where a value here disagrees with shipped code, correct it here and ship.
- **Shipping writes into other repositories:** run it only from Jo's Mac terminal, never while a Claude Code session works
  in that repository. A session hands Jo one fenced block labelled with where it runs.
- **Git:** this repository's commits come from Jo's Mac terminal. `archive/seed-2026-04/` is history; nothing there is a
  rule.
- **Lessons:** the cross-project lessons have one home, `~/Claude co-work/Projects/LESSONS.md`; nothing here keeps a
  `LESSONS.md`.
- Jo's language rules on anything shown to a user: Western digits, no emoji, the product's own copy; Noto Naskh Arabic
  and Lora unless a project chose a display face in ب-1.
